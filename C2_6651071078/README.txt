BÀI 4 - DỰ ÁN CÁ NHÂN: BLOG GIỚI THIỆU BẢN THÂN SINH VIÊN
============================================================

1. Thư mục:
- figma/       : link.txt và mockup thiết kế tham khảo
- html/        : index.html + link đến css/style.css
- css/         : style.css
- images/      : toàn bộ hình ảnh SVG dùng trong bài
- html_css_chung/ : phiên bản HTML + CSS chung một file

2. Trước khi nộp:
- Mở html/index.html và thay [HỌ VÀ TÊN], [MSSV].
- Có thể đổi email, GitHub, Facebook, Instagram.
- Nếu có Figma thật, dán link chia sẻ chế độ xem vào figma/link.txt.

3. CSS3 đã áp dụng:
- Selector
- Border & Background
- Text Effects
- 2D/3D Transform
- Transitions & Animations
- Multiple Columns / Grid
- Responsive User Interface

4. Lưu ý:
Ảnh trong images/ là SVG nội bộ nên mở bài không phụ thuộc Internet.
